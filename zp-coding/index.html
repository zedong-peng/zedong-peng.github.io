Method

        
A fixed prompt, a clean directory, one attempt. The measurement is what the
        agent saw, not a human judgement of quality.


        

          

            01
            
One prompt

            
Every run receives the same instruction, verbatim. The prompt is in the task card above.

          

          

            02
            
One attempt

            
No retries, no follow-up turns, no human edits. A provider error is a result, not a hidden rerun.

          

          

            03
            
Raw artifact

            
The model writes one HTML file in an empty directory. The file is shown in a sandbox, unmodified.

          

        


        
What a row contains

        

          
Configuration
Model, effort, provider and agent harness (Claude Code, Codex, Cursor, opencode, pi, dsh). Together they identify the attempt; none of them is a proxy for “the model”, and the same model under two agents is two different rows.

          
Status
ok means a file was written; reply means the model pasted HTML into the chat; no-file, error and timeout are failures.

          
Output tokens
Visible output plus reasoning tokens. Input includes uncached input, cache reads and cache writes.

          
Time & cost
Wall-clock duration and list-price cost from the agent event stream. A subscription bill can be smaller.

        


        
What this is not

        
This is a contact sheet, not a leaderboard. One sample per configuration says what
        happened once, not what a model can do. There is no human preference score, no pass@k, and no
        claim that a provider's routing is the model's default. Models are shown with their provider and
        agent because those change the result.
