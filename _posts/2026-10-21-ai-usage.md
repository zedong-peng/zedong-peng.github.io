Each request is counted once, cached input is priced on its own, and days are kept after a tool prunes its logs. The collector is in [`_scripts/ai-usage`](https://github.com/zedong-peng/zedong-peng.github.io/tree/main/_scripts/ai-usage).

To see your own, run this on each machine you code on, then drop the `tokendust-<machine>.json` files on [tokendust](/tokendust/):

```bash
curl -fsSL https://zedongpeng.com/tokendust/scan.py | python3 -
```

It counts only tools that keep local logs, so web chats are missing, and it shows list price, not your bill.
