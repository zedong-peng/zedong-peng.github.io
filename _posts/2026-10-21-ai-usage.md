Every tool that talks to a model now keeps a local record of what it sent and got back. I read those records on three machines — a Mac, one Linux box at home, and one FPGA server at the lab — merge them on the Mac once a day, and commit the result to this repository. The chart below is the merge: what I used, not what I paid.

There is a reason to publish it rather than keep it in a spreadsheet. Subscriptions hide the quantity. A flat monthly fee makes a heavy day and a quiet day look identical, and it is easy to believe that most of the cost comes from the few long sessions. For me it does not: a handful of agent loops dominate everything, and the rest of the year is noise on the same axis.

## What is counted

Each machine reads its own logs, so nothing leaves except daily totals per tool and model. The sources are Claude Code, Codex, OpenCode and pi session logs, plus Cursor's dashboard, which is the one tool that keeps usage server-side and is therefore read from the Mac only.

The accounting rules that matter:

- **One request is counted once.** Claude Code writes a line per content block and copies responses into several transcripts; rows are deduplicated by message id and request id, the same rule [ccusage](https://github.com/ccusage/ccusage) uses. Codex reports cumulative snapshots, so repeated totals are dropped, and a sub-agent's replay of its parent's history is not counted again. pi writes one row per request; a forked session copies its parent's entries, so those are deduplicated by provider response id.
- **Cached input is separate.** Uncached input, cache reads and cache writes are three columns, not one, because their prices differ by an order of magnitude.
- **Everything is priced at list.** The chart shows what the same tokens would cost at official API rates, using a price table checked into the repository. Subscription plans make the real bill smaller, sometimes much smaller; that is the point of comparing.
- **History outlives the logs.** Claude Code drops logs after about thirty days, so the collector keeps its own per-machine history and merges by keeping the larger count for a day. Days do not shrink when a log is pruned.

## How it runs

A `launchd` job on the Mac runs at nine every morning. It connects to the other two machines over ssh, pipes a standard-library-only Python script to each one, merges the three results, and commits `assets/ai-usage/data.json` only if the rows changed. The push rebuilds this site, so the chart above is a static file — no server, no API, and the history is in git.

Adding a machine is one line of configuration; adding a tool backend is one function. The collector and its tests live in [`_scripts/ai-usage`](https://github.com/zedong-peng/zedong-peng.github.io/tree/main/_scripts/ai-usage).

## Want the same picture of yours?

Most of that machinery exists because I wanted to see one number, and the interesting part is not my number. So the collector and the board are now a separate tool, [tokendust](https://github.com/zedong-peng/tokendust). On each machine you code on, one command, nothing to install:

```bash
curl -fsSL https://zedongpeng.com/assets/tokendust/scan.py | python3 -
```

It reads the logs already on disk and writes `tokendust-<machine>.json`. Drop those files on [the board](/tokendust/) and you get the chart above with your name on it — plus a card you can post, which is the whole point.

Three things worth saying plainly:

- **It sees less than you might hope.** Browsers keep no local log. If your hours go into the ChatGPT or Claude web apps, they are invisible to this, and the number will look small for a reason. CLI and IDE agents write logs; that is what gets counted.
- **It is list price, not your bill.** The same caveat as above, and the board says so next to the number rather than in a footnote.
- **Already on [ccusage](https://github.com/ccusage/ccusage)?** Drop its JSON instead. ccusage counts more tools than I do; the thing I added is summing several machines without a server, and a card that carries the link back so the next person can find it.

Nothing leaves the browser, and the repo is MIT.
