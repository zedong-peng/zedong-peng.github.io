llmwiki: A Literature Library for Research Agents

Created on October 19, 2026

2026   ·   life

EN
Prompt for your AI agent

Read https://zedongpeng.com/blog/2026/llmwiki/ and set up the same literature wiki for me.
Install the two skills from https://github.com/zedong-peng/llmwiki-skill (llmwiki-query and llmwiki-collect) where the coding agent I use will find them, without overwriting anything already installed.
Create a private git repository for the wiki at a path I choose, with the layout in skills/llmwiki-collect/scaffold-template.md.
Ask me for my research topics, then ingest one paper I name as a test and show me its citation.bib and note.md.

A coding agent forgets every paper it read when its session ends, and from memory it invents citations. So my agents keep a library: llmwiki, a private git repository with one folder per paper, blog post or codebase they have read, after Karpathy’s LLM wiki.

wiki/research/<topic>/
  index.md              what the topic knows, and its references
  assets/<slug>/        one reference, e.g. example-2025
    citation.bib        its key is the folder name
    note.md             written only after reading
    paper-pdf/  paper-tex/  github-repo/

Three rules keep it honest: each reference exists once; no note.md means not read; every ingestion is a commit. The wiki holds only other people’s work. Our own results stay in each project’s notes.

Set up your own

Copy the prompt at the top of this post into your agent, or install the two skills by hand. For Claude Code:

git clone https://github.com/zedong-peng/llmwiki-skill.git
mkdir -p ~/.claude/skills
ln -s "$PWD/llmwiki-skill/skills/llmwiki-query" ~/.claude/skills/
ln -s "$PWD/llmwiki-skill/skills/llmwiki-collect" ~/.claude/skills/

Keep the wiki private: the PDFs belong to their publishers. Then ask in plain words:

Use llmwiki-collect to ingest https://arxiv.org/abs/<id> into <wiki path> under the topic <topic>.
Use llmwiki-query: what does <wiki path> say about <question>?
