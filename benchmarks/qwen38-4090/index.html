Speed comparison

    Measured speed and deployment configuration. Select a column heading to sort.

    These are speed measurements, with different quantizations and KV caches. Code and prose were capped at 512 output tokens and truncated; JSON completed and parsed. The recorded fenced-code syntax checks failed; semantic tests were not run. The bars do not establish equal quality or a universal winner.

    What is comparable?

    Every measured configuration used the same physical RTX 4090, sequentially: batch 1, 4,096-token configured capacity, 34–77-token inputs, greedy decoding, thinking off, and three repetitions of each workload. GPU snapshots are included with the evidence; the shared machine was not reserved exclusively.

    HTTP decode speed is (output tokens − 1) / decode time. HTTP end-to-end speed is output tokens / client wall time, including prefill. The non-streaming benchmark does not measure time to first token.

    Native generation speed uses output tokens / generation time; in-process call speed also includes prefill. Native and HTTP results have different timing boundaries and are shown separately. Public reports below have their own protocols and are not ranked against these runs.
